# Classy Crest | E-commerce Website (Bootstrap)

A responsive demo online clothing store built with HTML, CSS and Bootstrap 4 while learning front-end development.

**Live demo:** add your GitHub Pages link here

## Pages
- `index.html`: home page with banner slider, top brands and products
- `p.html`: product listing with a collapsible winter collection menu
- `pd.html`: product detail page
- `signup.html`: sign-up form with phone number validation
- `login.html`: login form

## Built with
HTML5, CSS3, Bootstrap 4, a little JavaScript, Font Awesome

## What I practiced
- Responsive layouts with the Bootstrap grid and navbar
- Carousel, cards, accordion and forms
- Hover zoom effect on product images with CSS
- Form validation using HTML attributes

## Run it locally
Download or clone the repository and open `index.html` in a browser (or use the VS Code Live Server extension).
